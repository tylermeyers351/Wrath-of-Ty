# What Remains of Me

**What Remains of Me** is an experimental project developed as a minimum viable product (MVP), inspired by third-person hack-and-slash titles like *Elden Ring* and *God of War*.

## Purpose

The primary goal of this project was to **learn by building**. It focuses on three core areas of game development:

- 🎮 **Third-Person Gameplay Mechanics**  
- 📖 **Story-Building**  
- 🏰 **Level Design**

This prototype represents an early step in exploring those systems and refining my game development skills through hands-on experimentation.
